# 企业日语标点说明

## 两阶段策略

| 阶段 | 模式 | 日文标点 |
|------|------|----------|
| **生产推荐** | `asr_backend=runtime` + FunASR Runtime ≥1.12 | SenseVoiceSmall **2pass-offline** → `final`（Runtime 侧句读） |
| **阶段一** | `asr_backend=sensevoice` + `language=ja` | 整段 ITN + `ja_apply_punctuation`（短语空格 → `、`、句末 `。`） |

## SenseVoice 嵌入式（当前默认）

- 流式 **認識原文**：`use_itn=False`，无句读（设计如此）。
- **確定稿**：整段 `use_itn=True`；日语 ITN 常输出 **空格分句** 而非 `、` `。`。
- 配置 `ja_apply_punctuation: true`（默认）时，定稿后自动：
  - 短语间空格 → `、`
  - 句末补 `。`（并做 `，。` 等归一）

**不要**对日语使用 `ct-punc`（中文标点模型）；`config.enterprise.yaml` 中 `punc_model: ""`。

## Runtime 部署（企业级推荐）

1. 使用镜像 `funasr-runtime-sdk-online-cpu-0.1.12` 或更新。
2. 在 `deploy/runtime.env` 配置 **2pass** 模型，例如离线主模型：
   - `RUNTIME_MODEL_PATH=iic/SenseVoiceSmall`（需本机已下载并含 `model_quant.onnx`）
   - 在线流式模型仍可用 Paraformer-online 占位（见 FunASR issue #2035 示例）。
3. 启动：`docker compose -f deploy/docker-compose.yml up -d`
4. 网关：`python scripts/run_server.py --config config.runtime.yaml`

详见 [FunASR Runtime 2pass 文档](https://github.com/modelscope/FunASR/blob/main/runtime/docs/SDK_advanced_guide_online_zh.md)。

- [ ] **認識原文** 仍为无标点草稿
