## 六、启动说明

```powershell
# 1. 模型目录与单人共用 ./models（见 FunASR运行时调研.md）
copy deploy\runtime.meeting.env.example deploy\runtime.meeting.env

# 2. Runtime + 网关
docker compose -f deploy/docker-compose.meeting.yml --env-file deploy/runtime.meeting.env up -d

# 或本地
$env:PYTHONPATH="src"
python scripts/run_server.py --config config.meeting.yaml
```
