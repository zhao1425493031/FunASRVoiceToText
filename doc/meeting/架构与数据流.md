# 多人会议架构与数据流

## 组件

| 组件 | 端口 | 配置 |
|------|------|------|
| Apache | 443 | 反代单人/多人 |
| voicetotext-gateway-meeting | 8766 | `config.meeting.yaml` |
| funasr-runtime-meeting | 10096 | `deploy/runtime.meeting.env` |

## 数据流

```mermaid
flowchart LR
  PCM[PCM_19200] --> Handler[MeetingWSProtocolHandler]
  Handler --> Client[MeetingRuntimeWSClient]
  Client --> RT[Runtime_2pass]
  RT --> Map[map_runtime_to_meeting]
  Map --> Assign[MeetingSpeakerAssigner]
  Assign --> V2[partial_final_v2]
```

## 代码映射

| 职责 | 文件 |
|------|------|
| WS v2 | `src/voicetotext/server/meeting_ws_protocol.py` |
| Runtime 桥 | `src/voicetotext/asr/meeting_runtime_client.py` |
| 说话人 | `src/voicetotext/asr/meeting_speaker.py` |
| 应用入口 | `src/voicetotext/server/meeting_app.py`（无单人 `/ws/asr`） |
| 路由 | `/ws/meeting/asr` |

## 与单人对比

- 单人：`WSProtocolHandler` + `StreamSession` 或 `RuntimeWSSession` → `/ws/asr`
- 多人：`MeetingWSProtocolHandler` + `MeetingRuntimeWSSession` → `/ws/meeting/asr`，**无** `_session_pcm`
