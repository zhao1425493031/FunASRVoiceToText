# 多人会议架构与数据流（v2）

## 组件

| 组件 | 端口 | 配置 |
|------|------|------|
| voicetotext-meeting | 8766 | `config.meeting.yaml` |
| Apache（将来） | 443 | 反代 HTTPS / WSS |

## 数据流

```mermaid
flowchart LR
  PCM[PCM_19200] --> Handler[MeetingWSProtocolHandler]
  Handler --> Session[MeetingStreamSession]
  Session --> Engine[MeetingQwenEngine]
  Engine --> VAD[FSMN_VAD]
  Engine --> QwenP[Qwen3_0.6B]
  Engine --> QwenF[Qwen3_1.7B]
  Engine --> Pyannote[PyannoteWorker]
  Pyannote --> Merge[SpeakerTimelineMerger]
  Merge --> V2[partial_final_v2]
```

| 职责 | 文件 |
