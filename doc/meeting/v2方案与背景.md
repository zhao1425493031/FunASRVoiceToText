# 多人会议 ASR v2 — 方案与背景

> **已被 v3 取代**：当前生产路径见 [v3方案与背景.md](./v3方案与背景.md)、[v3实施总结.md](./v3实施总结.md)。勿再按本文部署 Qwen3 双模型栈。

> v1（SenseVoice + cam++ 句后聚类）已被 v2 取代，详见 [v2实施总结.md](./v2实施总结.md)。

## 背景

- 单麦多人会议场景下，v1 在**整句 utterance 定稿后**才用 cam++ 声纹聚类贴 `speaker_id`，与真实说话人时间轴不同步。
- 短插话、重叠说话、VAD 合段会导致 `speaker_id` 系统性错误。
- 开发环境：Windows + Python + HTTPS 内网手机调试；生产：Apache 反代 `8766`，`device: cuda`。

## 实施目的

1. **FSMN-VAD** 作为唯一生产 VAD，驱动句界。
2. **Qwen3-ASR-0.6B** 负责 partial，**Qwen3-ASR-1.7B** 负责 final（同一代码路径，`device` 仅切换性能）。
3. **Pyannote Community-1** `exclusive_speaker_diarization` 作为唯一说话人时间轴。
4. 保留 WebSocket **协议 v2**、鉴权、HTTPS、`web/meeting.html`。

## 方案与模型分工

| 组件 | 模型 | 分工 |
|------|------|------|
| VAD | fsmn-vad | 语音活动、句界 |
| ASR partial | Qwen/Qwen3-ASR-0.6B | 实时中间字幕 |
| ASR final | Qwen/Qwen3-ASR-1.7B | 句末定稿 |
| 说话人 | pyannote/speaker-diarization-community-1 | 滑窗 diarization → exclusive 段 |
| 胶水 | FunASR AutoModel | 加载 Qwen + VAD |

## 与 v1 差异

| 项 | v1 | v2 |
|----|----|-----|
| ASR | SenseVoiceSmall | Qwen3 双模型 |
| VAD | 能量阈值为主 | FSMN-VAD |
| 说话人 | cam++ 句后聚类 | Pyannote 时间轴合并 |
| asr_backend | embedded | meeting_qwen |

## 统一架构约束

- `device: cpu`（本地）与 `device: cuda`（服务器）**同一套业务代码**，禁止两套分支实现。
- 语言 `ja` / `zh` 由 `config.meeting.yaml` 默认，客户端 `start.language` 可覆盖。
