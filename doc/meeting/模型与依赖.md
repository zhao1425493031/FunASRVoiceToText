# 会议 ASR v2 — 模型与依赖

## Python 依赖

```bash
pip install -r requirements-meeting.txt
pip install -e .
```

| 包 | 版本 | 用途 |
|----|------|------|
| funasr | >=1.3.3 | FSMN-VAD、Qwen3 AutoModel |
| pyannote.audio | >=4.0 | Community-1 diarization |
| torch / torchaudio | >=2.0 | 推理 |
| fastapi / uvicorn | 见 requirements | 服务 |

## 模型

| 配置键 | 默认模型 |
|--------|----------|
| vad_model | fsmn-vad |
| qwen_partial_model | Qwen/Qwen3-ASR-0.6B |
| qwen_final_model | Qwen/Qwen3-ASR-1.7B |
| pyannote_model | pyannote/speaker-diarization-community-1 |

## Hugging Face

1. 访问 https://huggingface.co/pyannote/speaker-diarization-community-1 接受许可。
2. 创建 Token：https://huggingface.co/settings/tokens
3. Windows（PowerShell）：

```powershell
$env:HF_TOKEN = "hf_xxxxxxxx"
```

配置项 `pyannote_hf_token_env` 默认为 `HF_TOKEN`。

## 设备

| 环境 | config.meeting.yaml |
|------|---------------------|
| Windows 本地调试 | `device: cpu` |
| GPU 服务器 | `device: cuda` |

同一套代码，仅改 `device` 与性能预期。

## 语言

- `language: ja` 或 `zh`
- 一次会议一种语言；客户端 `start.language` 可覆盖配置默认值。
