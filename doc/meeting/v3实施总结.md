## 运行说明

1. `pip install -r requirements-meeting.txt && pip install -e .`
2. 配置 `secrets.meeting.yaml` 中的 `hf_token`
3. `python scripts/run_meeting.py`
4. 等待日志 `MeetingSenseVoiceEngine ready`
5. 本地 `device: cpu`；服务器改为 `device: cuda`

## 已知限制

1. SenseVoice 无 Paraformer 式 `chunk_size` 真流式，partial 为累积窗重识别，延迟与抖动高于 v2 Qwen。
2. Pyannote 滑窗步长（默认 4s）导致 `speaker_id` 相对 final 可能有 ≤15s 延迟。
3. 首次启动需下载 SenseVoice + FSMN-VAD + Pyannote 权重；需 `HF_TOKEN`。
4. CPU 环境整体延迟高，行为与 CUDA 一致但性能不同。
