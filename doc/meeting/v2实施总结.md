## 运行说明

1. `pip install -r requirements-meeting.txt && pip install -e .`
2. 设置 `$env:HF_TOKEN`
3. `python scripts/run_meeting.py`
4. 本地 `device: cpu`；服务器改为 `device: cuda`

## 已知限制

- 本地无 GPU 时 Qwen3/Pyannote 延迟高，行为与服务器一致。
- Pyannote 滑窗步长 5s，说话人标签相对 final 可能有 ≤15s 延迟。
- 首次启动需下载 HF/FunASR 模型。
