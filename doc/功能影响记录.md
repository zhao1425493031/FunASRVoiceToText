# 功能影响记录



## 会议 ASR v3（当前生产路径）



| 影响域 | 说明 |

|--------|------|

| ASR 模型 | Qwen3-0.6B/1.7B **移除**；改为 SenseVoiceSmall 单模型 |

| 配置键 | `qwen_partial_model`/`qwen_final_model`/`funasr_hub` **删除**；恢复 `asr_model` |

| asr_backend | `meeting_qwen` → `meeting_sensevoice`；`embedded` 继续禁止 |

| 依赖 | `qwen-asr` **移除**；保留 funasr + pyannote + torch |

| 定稿策略 | `meeting_reuse_partial_for_final` 语义变为复用 partial **文本草稿** |

| 流式延迟 | SenseVoice 窗级识别，partial 首字延迟可能高于 Qwen |

| 说话人 | **行业策略**：`meeting_spk_primary=embedding` 句级 campplus 为主；Pyannote 为辅（`meeting_pyannote_min_overlap_ms`）；每 WS 会话 `reset_session` |
| 配置键（新增） | `meeting_spk_primary`、`meeting_pyannote_min_overlap_ms`、`pyannote_context_sec`、`meeting_spk_embedding_*` |
| device | `resolve_device()`：CUDA 不可用时安全回退 CPU（Windows 无 CUDA torch 可稳定 `auto`） |
| 多连接 | 每 WS `SpeakerSessionContext` 隔离；`max_ws_connections` 默认 1；Pyannote 无绑定时停算 |

| VAD | **不变**：FSMN-VAD |

| 协议 | WebSocket v2 **不变** |

| 删除文件 | `meeting_qwen_engine.py`、`qwen_funasr_engine.py`、`embedded_engine.py` 及对应测试 |



## 会议 ASR v2（已废止）



| 影响域 | 说明 |

|--------|------|

| 模型 | SenseVoice、cam++ **已移除**；改用 Qwen3-0.6B/1.7B + Pyannote Community-1 |

| 配置 | `asr_backend: meeting_qwen`；新增 `qwen_*`、`pyannote_*` |

| 依赖 | `requirements-meeting.txt`；需 `HF_TOKEN` 与 Pyannote HF 许可 |



详见 [meeting/v2实施总结.md](meeting/v2实施总结.md)（顶部已标注被 v3 取代）。

## 会议 LLM 会议纪要

| 影响域 | 说明 |
|--------|------|
| 行为变更 | `llm.enabled=true` 时会后自动生成纪要；WS 新增 `summary_progress`、`meeting_summary`；落盘 `out/meetings/` |
| 协议变更 | v2 扩展 `end.skip_summary`；会后保持 WS 直至纪要完成 |
| 配置变更 | `config.meeting.yaml` 的 `llm` 段；`api_key` 写在 yaml |
| HTTP | 新增 `POST /api/v1/meeting/summarize`、`GET /api/v1/meeting/sessions/{id}`；`/ready` 增加 `detail.llm` |
| 前端 | 纪要面板、复制/下载 md、end 后等待推送 |
| 主开关 | `llm.enabled`（非命令行）；跳过纪要仅 `end.skip_summary=true` |
| 不变项 | 会中 partial/final 时序、PCM 19200 字节、FSMN+SenseVoice+Pyannote、HF token 走 secrets |

详见 [meeting/LLM纪要方案.md](meeting/LLM纪要方案.md)、[meeting/LLM实施总结.md](meeting/LLM实施总结.md)。
