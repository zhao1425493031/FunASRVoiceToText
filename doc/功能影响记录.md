# 功能影响记录

## 2026-06-05 LLM 会议纪要

- 新增 LLM 模块：`transcript_format`、`prompts`、`client`、`parse`、`summary_service`、`providers`、`factory`
- `llm.enabled: true` 时转写完成后自动调用 DashScope（Qwen）生成结构化会议纪要
- 产物新增：`summary` 对象（title/overview/topics/decisions/action_items/markdown）、`{job_id}.summary.md`
- `POST /api/v1/summarize`：enabled 返回 200，disabled 返回 501 `llm_disabled`
- job status / get job 响应新增 `summary` 字段；`/ready` detail 新增 `llm` 状态
- CLI 新增 `--no-summary`；`config.yaml` llm 段扩展（api_key 写在 config.yaml）
- `on_failure: warn`（默认）时 LLM 失败不阻断转写；`fail` 时整 job 失败
- 不变：Diar-First 转写逻辑、HF token 走 secrets、segments schema
- 依赖新增：`httpx`

## 2026-06-05 日语文本美化（beautify）

- 新增 `batch_text_beautify.py`：去除词内空格、修复断词（でしょうか/ございます等）、补全句号
- 导出 `meta.text_beautified: true`

## 2026-06-05 片段合并与文本整理（polish）

- 新增 `batch_segment_polish.py`：修复「採用いたします」跨窗断裂、合并同说话人相邻段、整理 ASR 空格
- 导出 `meta.segment_polished: true`

## 2026-06-05 说话人标签精炼（refine）

- 新增 `batch_speaker_refine.py`：去除开头噪声段、修正问后短答「はい」、应答「わかりました」、结尾「こちらこそ」
- `batch_diar_segments.py`：短段误标重分配、去除开头孤立 diar 段
- 导出 `meta.speaker_refined: true`

## 2026-06-05 Diar-First 说话人分离改进

- 批处理管线由 VAD-first + 后对齐改为 **Diar-First**（Pyannote 先分段 → 逐窗 ASR → 直接贴说话人标签）
- 新增 `batch_diar_segments.py`、`batch_transcribe.py`；`batch_align.build_aligned_from_diar()`
- `BatchPipeline` 不再加载/调用 `FunASRVAD`；`align_batch_segments()` 仅保留供单测
- `config.yaml`：`pyannote_min/max_speakers` 默认改为 2；新增 `batch_diar_merge_gap_ms`、`batch_diar_min_segment_ms`、`batch_asr_parallel_workers`
- 导出 `meta` 新增 `pipeline`、`diar_windows`、`stamp_sents_available`
- diar 结果为空时抛出 `DiarizationEmptyError`
- CLI / HTTP 接口不变；segment 数量与说话人准确度预期提升

## 2026-06-05 精简为「仅音频文件转写」

- 删除实时会议全套（meeting 服务、WebSocket、麦克风前端）
- 删除 `config.meeting.yaml`，统一为 `config.yaml`
- 删除 `requirements-meeting.txt` / `requirements-batch.txt`，统一 `requirements.txt`
- 保留：批处理 CLI、网页 `/batch`、Pyannote 说话人分离、LLM 占位
