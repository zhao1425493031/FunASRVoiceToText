# 功能影响记录

## 变更摘要（企业日语双阶段）

| 影响域 | 变更 | 缓解 |
|--------|------|------|
| 识别语言 | 默认中文 → 日语 SenseVoice | `language: ja` 固定生产配置 |
| 延迟 | 伪流式 2s 窗口，高于原 600ms Paraformer | 阶段二 Runtime 2pass 降低延迟 |
| 模型体积 | SenseVoice + 可选 Runtime 镜像 | 内网预拉 `~/.cache/modelscope` 与 Docker 模型卷 |
| 鉴权 | enterprise 配置强制 API Key | 部署轮换 Key；Web 使用 `?key=` |
| 兼容性 | Paraformer 路径保留于 `asr_backend=paraformer` | 生产不用 |
| 运维 | 阶段二双进程 | Compose 健康检查；先 Runtime 后 gateway |

## 公开发布定稿（方案 B）

| 影响域 | 变更 | 缓解 |
|--------|------|------|
| 内存 | 每 WS 连接累积整段 PCM，上限 `session_pcm_max_seconds`（默认 600s ≈ 19MB） | 可配置缩短；`finalize`/`reset` 即释放 |
| final 与 partial | 停止后 `final` 可能与 `partial` 措辞略有差异 | **以 `final` 为准**提交 AI |
| 延迟 | 停止后整段 SenseVoice 推理 + 可选 ct-punc 加载 | 生产终态用 Runtime 2pass |
| 标点 | 企业配置 `punc_model: ct-punc` 懒加载 | 仅 finalize 兜底时加载 |
| 隐私 | PCM 仅内存、会话结束丢弃 | 文档明确不落盘 |

## API 变更

- 新增 `GET /ready`
- 新增 `POST /api/transcribe`（WAV）
- WebSocket `start` 可选字段 `api_key`
- WebSocket `error` code：`session_too_long`（超过 `session_pcm_max_seconds`）
- 配置项：`asr_backend`、`stream_window_ms`、`session_pcm_max_seconds`、`punc_model`、`api_key`、`max_ws_connections`、`runtime_*`
