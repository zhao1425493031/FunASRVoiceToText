# 功能影响记录（会议服务）

本仓库为 **仅多人会议实时字幕**，**纯 Python embedded**（无 Docker / 无 C++ Runtime）。说话人采用 **cam++ 声纹嵌入 + 会话级聚类**（非每句局部 spk 编号）。

| 影响域 | 说明 |
|--------|------|
| 配置 | 仅 `config.meeting.yaml`，`asr_backend: embedded` |
| 入口 | `scripts/run_meeting.py` → `meeting_app.py` |
| 文档 | `doc/meeting/` |

已删除：Docker Compose、Runtime WebSocket 客户端、`deploy/` 部署文件。

详见 [meeting/实施总结.md](meeting/实施总结.md)。
