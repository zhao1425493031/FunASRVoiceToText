# 离线批处理方案与背景

## 背景

企业需要将会议录音归档为可检索文本：日文转写、段级时间戳、说话人分离，并为后续 LLM 纪要预留数据结构。

## 实施目的

- 转写：`iic/SenseVoiceSmall` 全文件（SenseVoiceLarge 未公开发布）
- 说话人：`pyannote/speaker-diarization-community-1` 整文件 diarization
- 产物：JSON / Markdown / SRT / summary.md，schema 含结构化 `summary`（LLM 已实现）
- 入口：CLI + REST `POST /api/v1/transcribe`

## 与实时会议的区别

| 项 | 实时 meeting | 离线 batch |
|----|--------------|------------|
| ASR | SenseVoiceSmall | SenseVoiceLarge |
| Diarization | 滑窗 PyannoteWorker | 整文件 PyannoteOfflineDiarizer |
| 延迟 | 首字 ≤10s 目标 | 无实时要求 |
| 端口 | 8766 | 8767 |

## 配置

- [`config.batch.yaml`](../../config.batch.yaml)
- HF Token：`secrets.meeting.yaml` 或环境变量 `HF_TOKEN`（不入库）

## 启动

```bash
# CLI
python scripts/run_batch.py input.wav -o out/

# HTTP API
python scripts/run_batch.py --serve
```
