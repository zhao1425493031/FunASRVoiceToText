# 批处理架构与数据流

```mermaid
flowchart LR
  Input[audio file] --> Pre[audio_preprocess]
  Pre --> Dia[pyannote_offline]
  Dia --> Norm[batch_diar_segments]
  Norm --> ASR[batch_transcribe]
  ASR --> Build[build_aligned_from_diar]
  Build --> Polish[refine + polish + beautify]
  Polish --> Summary[LLM summary]
  Summary --> Export[json md srt summary.md]
```

## 模块映射

| 模块 | 路径 |
|------|------|
| 预处理 | `src/voicetotext/asr/audio_preprocess.py` |
| diar 规范化 | `src/voicetotext/asr/batch_diar_segments.py` |
| diar 窗口转写 | `src/voicetotext/asr/batch_transcribe.py` |
| ASR | `src/voicetotext/asr/sensevoice_funasr_engine.py` |
| 整文件 diar | `src/voicetotext/asr/pyannote_offline.py` |
| 说话人贴标 | `src/voicetotext/asr/batch_align.py`（`build_aligned_from_diar`） |
| 编排 | `src/voicetotext/asr/batch_pipeline.py` |
| LLM 纪要 | `src/voicetotext/llm/summary_service.py` |
| HTTP | `src/voicetotext/server/batch_app.py` |
| CLI | `scripts/run_batch.py` |

> `funasr_vad.py` 仍保留于仓库供单测，批处理主路径不再调用。
