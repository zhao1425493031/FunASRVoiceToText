# 批处理实施总结

## 新建代码

| 文件 | 说明 |
|------|------|
| `config.batch.yaml` | 批处理配置 |
| `src/voicetotext/asr/audio_preprocess.py` | 16k mono 加载 |
| `src/voicetotext/asr/pyannote_offline.py` | 整文件 diarization |
| `src/voicetotext/asr/batch_align.py` | ASR↔Diar 时间重叠对齐 |
| `src/voicetotext/asr/batch_pipeline.py` | 编排与导出 |
| `src/voicetotext/server/batch_app.py` | FastAPI 批处理服务 |
| `scripts/run_batch.py` | CLI / --serve |
| `src/voicetotext/llm/*` | LLM 会议纪要（DashScope/Qwen，结构化 summary） |
| `tests/test_batch_*.py`, `test_llm_stub.py` | 单测 |

## 复用代码

- `sensevoice_funasr_engine.py`（model_id 由配置注入 Large）
- `funasr_vad.py`（新增 `segment_utterances`）
- `speaker_timeline.py`（`SpeakerTimelineMerger` 算法）
- `config.py`（扩展 batch 模式与 llm 段）

## 使用说明

1. 配置 `secrets.meeting.yaml`（hf_token，勿提交 git）
2. `python scripts/run_batch.py meeting.wav -o out/`
3. 或 `python scripts/run_batch.py --serve`，`POST /api/v1/transcribe` 上传音频

## LLM 预留

- `BatchTranscript.summary` 为结构化对象（`llm.enabled: true` 时）
- `POST /api/v1/summarize` → enabled 时 200，disabled 时 501
- 详见 `doc/batch/LLM实施总结.md`
